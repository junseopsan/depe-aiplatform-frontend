# feat/DAP-484-pdf-viewer-component

## 개요
PDF 파일을 브라우저에서 렌더링하는 뷰어 컴포넌트 (UiPdfViewer)

## 요구사항
- 페이지 이동: 이전/다음 버튼, 페이지 번호 직접 입력
- 썸네일 패널: 좌측에 전체 페이지 썸네일 표시, 클릭 시 해당 페이지로 이동, 토글로 열기/닫기
- 줌: 확대/축소 (0.4x ~ 2.0x), 퍼센트 클릭 시 100% 리셋
- 텍스트 검색: 검색바에서 Enter로 검색, 매칭 페이지 간 이전/다음 이동, 검색어 노란색 하이라이트
- 외부 검색어: searchText prop으로 초기 검색어 전달 시 자동 검색 + 첫 번째 결과 페이지로 이동
- 로딩/에러 상태: 로딩 중 메시지, 실패 시 에러 메시지 표시
- 인쇄: 웹에서 바로 인쇄 (iframe + window.print 방식)
